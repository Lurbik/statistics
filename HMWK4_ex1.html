Welford’s recurrence formulas for the sum of squares and the variance

Starting from Knuth’s online update of the mean, we derive the recurrences for the sum of squared deviations SS and the variance, implement them in three lines of code and verify them numerically, including the floating-point case where the textbook formula fails.

00Notation

Observations x1, x2, … arrive one at a time. After n observations define

x̄n = (1/n) Σi=1n xi     SSn = Σi=1n (xi − x̄n)²     sn² = SSn / (n − 1)     σ̂n² = SSn / n

sn² is the (unbiased) sample variance, σ̂n² the population-style (biased) variance. Goal: update x̄, SS and the variance from x̄n−1, SSn−1 and the new value xn only, without storing or re-reading the previous data (one pass, O(1) memory).

01Knuth’s recurrence for the mean

Separate the last observation from the sum: n x̄n = Σi=1n−1 xi + xn = (n − 1) x̄n−1 + xn

Write (n − 1) x̄n−1 = n x̄n−1 − x̄n−1 and divide by n:

(K)x̄n = x̄n−1 + (xn − x̄n−1) / n,    x̄0 = 0

Interpretation: the new mean moves from the old one by a fraction 1/n of the “surprise” δn = xn − x̄n−1. Two consequences used below:

x̄n − x̄n−1 = δn/n      xn − x̄n = δn − δn/n = δn(n − 1)/n (K′)

02Recurrence for the sum of squares SS

Same idea as Knuth: isolate the last term and express everything through the previous quantities.

Split the sum and add and subtract x̄n−1 inside the first n − 1 terms:

SSn = Σi=1n−1 [ (xi − x̄n−1) + (x̄n−1 − x̄n) ]² + (xn − x̄n)²

Expand the square. The cross term vanishes because deviations from their own mean sum to zero, Σi=1n−1(xi − x̄n−1) = 0:

SSn = SSn−1 + (n − 1)(x̄n−1 − x̄n)² + (xn − x̄n)²

Substitute (K′): x̄n−1 − x̄n = −δn/n and xn − x̄n = δn(n − 1)/n:

SSn = SSn−1 + δn² [ (n − 1)/n² + (n − 1)²/n² ] = SSn−1 + δn² (n − 1)/n

Since δn(n − 1)/n = xn − x̄n, the same increment can be written with the old and the new mean:

(W)SSn = SSn−1 + (xn − x̄n−1)(xn − x̄n) = SSn−1 + ((n − 1)/n)(xn − x̄n−1)²,    SS0 = 0

Check at n = 1: δ1 = x1, x̄1 = x1, so SS1 = 0 · … = 0, as it must be. The increment is never negative, so SS can only grow — another property the textbook formula Σx² − nx̄² does not guarantee in floating point (section 06).

Alternative derivation from SSn = Σxi² − n x̄n²
SSn − SSn−1 = xn² − n x̄n² + (n − 1) x̄n−1²

Use (n − 1) x̄n−1 = n x̄n − xn (step 1 of Knuth) on one factor of the last term:

= xn² − n x̄n² + (n x̄n − xn) x̄n−1 = xn(xn − x̄n−1) − x̄n · n(x̄n − x̄n−1)

and n(x̄n − x̄n−1) = xn − x̄n−1, so the difference is (xn − x̄n−1)(xn − x̄n): the same result (W).

03Recurrence for the variance

Dividing (W) by the right denominator gives update rules for the variance itself, with exactly the same shape as Knuth’s rule (K): “old value + (new contribution − old value) / count”.

Sample variance (n ≥ 2). From (n − 1)sn² = (n − 2)sn−1² + δn(xn − x̄n):

(V)sn² = sn−1² + [ (xn − x̄n−1)(xn − x̄n) − sn−1² ] / (n − 1),    s1² := 0 (only as a starting value)

Population-style variance (n ≥ 1). From n σ̂n² = (n − 1) σ̂n−1² + δn(xn − x̄n):

(V′)σ̂n² = σ̂n−1² + [ (xn − x̄n−1)(xn − x̄n) − σ̂n−1² ] / n,    σ̂0² = 0

In (V′) the term δn(xn − x̄n) plays the role of xn in (K): the variance is the running mean of these “squared-deviation contributions”. In practice it is simpler to keep SS and divide only when the variance is requested, which is what the code does. The sample variance is defined only from n = 2; with a single observation there is no information about spread.

04Code: the core is three lines

JavaScript (used on these pages)

// state: n = count, mean = x̄, ss = SS (all start at 0)
function welfordUpdate(state, x) {
  state.n += 1;
  const delta = x - state.mean;          // δ = x − x̄ₙ₋₁
  state.mean += delta / state.n;         // (K)
  state.ss   += delta * (x - state.mean); // (W) uses old and new mean
}
const sampleVariance = s => s.n > 1 ? s.ss / (s.n - 1) : NaN;
const populationVariance = s => s.n > 0 ? s.ss / s.n : NaN;

Python (same logic)

# one pass, O(1) memory
n, mean, ss = 0, 0.0, 0.0
for x in data:
    n += 1
    delta = x - mean
    mean += delta / n
    ss += delta * (x - mean)
var_sample = ss / (n - 1) if n > 1 else float("nan")

The order matters: delta must be computed with the old mean, and the third line must use the new mean. Using the old mean twice would give δ², which over-counts by a factor n/(n − 1).

06Why not the “textbook” formula Σx² − n x̄²?

Algebraically SSn = Σxi² − n x̄n², and that formula is also one-pass (keep Σx and Σx²). In floating point, however, it subtracts two huge, almost equal numbers: when the data have a large mean compared with their spread, the leading digits cancel and only rounding error is left (catastrophic cancellation). Welford only ever accumulates deviations from the current mean, which are small.

Below, the same four values 4, 7, 13, 16 (exact sample variance 30) are shifted by a constant c. Shifting does not change the variance, so every row should read 30. Everything is computed live in IEEE-754 double precision.

A two-pass algorithm (first the mean, then Σ(x − x̄)²) is also accurate, but it needs the data twice. Welford is numerically stable in one pass: it avoids the cancellation of the textbook formula and in practice stays very close to the two-pass result, although (like any floating-point method) it does not always give identical accuracy or remove every rounding error. One pass is what a streaming setting — e.g. scores arriving one system at a time in Ex. 2 — requires.
